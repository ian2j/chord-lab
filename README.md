# Chord Lab

An in-browser playground for hearing and learning chords, keys, progressions and scales. Single file, no build step, Web Audio synthesis, optional MIDI keyboard input.

**Live:** https://ian2j.github.io/chord-lab/

- Hold notes (mouse, computer keys `A W S E D F T G Y H U J K`, or a MIDI keyboard) and the chord is named.
- Key pads: the seven chords of any key, playable with keys `1`–`7`.
- Chord explorer, progression builder with presets and shareable links, scale highlighter, and a short guide to reading chord symbols and Roman numerals.
